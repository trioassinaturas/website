# trioassinaturas.com.br

Site institucional da Trio Assinaturas — plataforma para clubes de assinatura.

Construído com [Astro](https://astro.build) (site estático, sem framework de UI).

## Comandos

```sh
npm install     # instala as dependências
npm run dev     # servidor de desenvolvimento em localhost:4321
npm run build   # gera o site estático em ./dist
npm run preview # serve o build localmente
```
