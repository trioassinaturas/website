Qualquer assistente que aceite servidores MCP remotos com login OAuth pode se
conectar ao Trio pelo mesmo endereço:

```
https://mcp.trioassinaturas.com.br/mcp
```

Em todos os casos o acesso é autorizado com o seu usuário do Trio — nenhuma
chave ou senha é copiada para o assistente.

## ChatGPT

<Steps>

1. Acesse [chatgpt.com](https://chatgpt.com) e abra **Configurações →
   Aplicativos e conectores**.

2. Em configurações avançadas, ative o **modo de desenvolvedor**, caso ainda
   não esteja ativo. Conectores personalizados estão disponíveis nos planos
   pagos do ChatGPT.

3. Clique em **Criar**, dê um nome (por exemplo, "Trio") e informe o endereço
   do servidor.

4. Selecione **OAuth** como autenticação e conclua o login com o seu email do
   Trio, autorizando as permissões desejadas.

</Steps>

## Ferramentas de programação

Se a sua equipe tem alguém técnico, as ferramentas de desenvolvimento com
suporte a MCP conectam com uma configuração curta.

<Tabs items={[{ id: "vscode", label: "VS Code" }, { id: "cursor", label: "Cursor" }, { id: "gemini", label: "Gemini CLI" }]}>
  <Fragment slot="vscode">

    Abra a paleta de comandos (Ctrl+Shift+P), execute **MCP: Add Server**,
    escolha o tipo **HTTP** e cole o endereço do servidor — ou adicione ao
    arquivo `.vscode/mcp.json`:

    ```json
    {
      "servers": {
        "trio": {
          "type": "http",
          "url": "https://mcp.trioassinaturas.com.br/mcp"
        }
      }
    }
    ```

  </Fragment>
  <Fragment slot="cursor">

    Adicione ao arquivo `~/.cursor/mcp.json` e clique em **Login** ao lado do
    servidor **trio** na seção MCP das configurações:

    ```json
    {
      "mcpServers": {
        "trio": {
          "url": "https://mcp.trioassinaturas.com.br/mcp"
        }
      }
    }
    ```

  </Fragment>
  <Fragment slot="gemini">

    No terminal, execute:

    ```
    gemini mcp add --transport http trio https://mcp.trioassinaturas.com.br/mcp
    ```

    Depois, dentro do Gemini CLI, execute `/mcp auth trio` e autorize no
    navegador.

  </Fragment>
</Tabs>

<Callout type="warning" title="Nem todo assistente conecta">

O Trio usa o método de identificação mais recente do protocolo MCP. Alguns
assistentes ainda não o adotaram — o Codex CLI da OpenAI, por exemplo — e não
conseguem concluir a autorização. Se um assistente parar na etapa de login, a
causa provável é essa, e a solução é aguardar uma atualização dele.

</Callout>
