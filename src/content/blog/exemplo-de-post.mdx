## Por onde começar

Antes de escolher um número, some tudo o que sai do seu bolso a cada ciclo. A
conta que importa é simples: _receita por assinante_ menos _custo por assinante_,
com o envio incluído. O resto é ajuste fino.

Três coisas que costumam ficar de fora da planilha:[^planilha]

- **Frete reverso**, que aparece quando o assinante troca o endereço tarde
- **Embalagem**, incluindo o material de proteção
  - Fita, plástico bolha e etiqueta somam mais do que parece
  - Vale medir o custo por caixa montada, não por item comprado
- **Taxa do meio de pagamento**, que muda entre cartão, Pix e boleto

### A ordem das decisões

1. Calcule o custo total do ciclo
2. Defina a margem mínima aceitável
3. Escolha os degraus de plano (mensal, trimestral, anual)
4. Só então pense em desconto por fidelidade

> Preço não é o que você acha que o produto vale. É o que sustenta a operação
> rodando no mês que vem.

A ordem importa: definir desconto antes de conhecer a margem é o caminho mais
rápido para vender no prejuízo.[^churn]

Note que o plano anual antecipa caixa, mas também antecipa risco: se o custo do
frete subir em março, você já vendeu o ano inteiro pelo preço de janeiro.[^frete]

  Reajuste contratual anual resolve boa parte disso. Deixe a regra clara na
  página de checkout, não escondida nos termos de uso.
</Callout>

## Modelando na prática

Um cálculo de margem por plano, do jeito mais direto possível:

```ts
type Plano = {
  nome: string
  precoCentavos: number
  meses: number
}

const CUSTO_CICLO_CENTAVOS = 5400

export function margemMensal(plano: Plano): number {
  const receitaMensal = plano.precoCentavos / plano.meses
  return (receitaMensal - CUSTO_CICLO_CENTAVOS) / receitaMensal
}
```

Para rodar isso rápido em cima de um CSV exportado da plataforma:

```bash
pnpm tsx scripts/margem.ts --input planos.csv --formato tabela
```

E o formato de configuração que a Trio espera para cada plano:

```json
{
  "nome": "Trimestral",
  "precoCentavos": 24900,
  "meses": 3,
  "renovacaoAutomatica": true
}
```
